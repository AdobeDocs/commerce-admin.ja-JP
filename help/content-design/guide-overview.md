# Adobe Commerce コンテンツおよびデザインガイド

このガイドは、Adobe CommerceおよびMagento Open Sourceの管理画面で作業するコンテンツデザイナーおよびマーチャンダイザーを対象としています。 基本的なコンテンツコンポーネントの構築など、コンテンツとデザイン機能に関する詳細な情報を提供します。 コア [!DNL Commerce]の設定と機能に関する基本的な理解を前提としています。

主な内容：

| 件名 | 説明 |
| ------- | ----------- |
| [はじめに](introduction.md) | コンテンツとサイトデザイン機能を使用して、ストアにブランディングとスタイルを反映する方法の概要。 |
| [&#x200B; コンテンツメニュー](content-menu.md) | [!UICONTROL Content] メニューを使用して、ストア内のコンテンツを管理するための複数の機能にアクセスします。 |
| デザイン | デザインツールを使用して、ストアフロントの[&#x200B; テーマ &#x200B;](themes.md)と[&#x200B; ページレイアウト &#x200B;](page-layout.md)を制御します。 [[!UICONTROL Design Configuration]](configuration.md)を使用すると、設定を1つのページに表示して、デザイン関連のルールと設定設定を簡単に編集できます。 |
| コンテンツ要素 | このセクションでは、コンテンツ [&#x200B; ページ &#x200B;](pages.md)と[&#x200B; ブロック &#x200B;](blocks.md)の作成と管理の詳細について説明し、[&#x200B; ウィジェット &#x200B;](widgets.md)を使用して動的コンテンツを追加します。 |
| [WYSIWYG Editor](editor.md) | エディターでは、コンテンツの&#x200B;_What You See Is What You Get_ （WYSIWYG）ビューで作業する際に入力および書式設定を行うことができます。 |
| メディア | [&#x200B; メディア ストレージ &#x200B;](media-storage.md)を使用すると、サーバーに保存されているメディア ファイルを整理してアクセスできます。 メディアアセットをアップロードし、[Adobe Stock](adobe-stock.md)を[!DNL Commerce]と統合して、ストアで使用する無数のメディアアセットにアクセスできます。 |
| [&#x200B; コンテンツ ステージング &#x200B;](content-staging.md) | コンテンツのステージング機能により、ビジネス部門は、管理画面から直接、ストアの様々なコンテンツ更新を簡単に作成、プレビュー、スケジュールできます。 |
